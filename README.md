# AnyIcon Web (애니아이콘 웹) - AI 커스텀 단축아이콘 & 스마트 런처 체인저

> **Vercel 배포 후 크롬 브라우저가 부여하는 볼품없는 단축아이콘 문제를 완벽 해결!**
> 원하는 사진, AI 생성 아트워크, 프리미엄 테마팩으로 PC·태블릿·스마트폰 어디서든 고화질 맞춤 단축아이콘을 생성하고 기존 단축아이콘을 원클릭으로 수정·교체할 수 있습니다.

---

## 🌟 주요 핵심 기능

### 1. 기존 단축아이콘 파일(.url) 드래그 앤 드롭 & URL 감지
- PC 바탕화면에 있는 기존 단축아이콘 파일(`.url`, 바로가기)을 브라우저에 **드래그 앤 드롭**하면, 사이트 주소(URL)와 이름을 자동으로 읽어옵니다.
- 이미지 파일(PNG, JPG, WebP)을 드래그하면 즉시 아이콘 이미지로 자동 불러옵니다.
- 웹사이트 URL 입력 시 파비콘 자동 감지 및 빠른 프리셋(유튜브, 넷플릭스, 노션, ChatGPT 등) 제공.

### 2. Any Icon 스타일 아이콘 제작 & AI 스튜디오
- **AI 아이콘 생성**: 3D 클레이/입체, 사이버 네온, 글래스모피즘, 모던 미니멀, 레트로 픽셀아트, 파스텔 감성 등 프롬프트 기반 고화질 아이콘 생성.
- **내 사진/이미지 편집**: 사진 업로드, 확대/축소(Zoom), 360도 회전, 감성 필터(비비드, 웜톤, 쿨톤, 흑백, 네온 글로우).
- **테마팩 라이브러리 (Any Icon 스타일)**: 60+ 이상의 인기 웹 서비스 및 감성 테마팩 내장.
- **외형 디테일 커스텀**: iOS 스퀴클(Squircle), 원형, 둥근 사각형, 네온 테두리, 알림 뱃지(숫자, 레드닷, 스타 등).

### 3. 기기별 원클릭 단축아이콘 교체 & 다운로드
- **스마트폰 / 태블릿 (Android Chrome & iOS Safari)**:
  - '홈 화면에 추가'를 누르면 동적 런처가 열리며, 크롬 메뉴(⋮)에서 [홈 화면에 추가] 클릭 시 **내가 만든 고화질 아이콘으로 즉시 등록**!
  - 탭하면 0.3초 스플래시 후 원래 사이트로 매끄럽게 자동 리다이렉트.
  - PC에서 만든 후 폰 카메라로 찍어 바로 등록할 수 있는 **QR 코드 기능 내장**.
- **PC / 노트북 (Windows & Mac)**:
  - 브라우저에서 순수 바이너리 `.ico` 파일과 `.url` (Windows 바로가기) 파일을 원클릭 자동 생성 다운로드.
  - 바탕화면에 두고 더블클릭하면 내 아이콘으로 크롬 즉시 실행.
- **Vercel 개발자용 패키지 (Favicon & PWA ZIP)**:
  - Vercel에 배포할 때 넣을 수 있는 `manifest.webmanifest`, `favicon.ico`, `icon-192.png`, `icon-512.png` 및 `<head>` 태그 코드를 압축한 ZIP 파일 원클릭 다운로드 제공.

## 🚀 Vercel 배포 방법

1. GitHub 저장소에 현재 폴더를 푸시합니다.
2. [Vercel 대시보드](https://vercel.com)에서 해당 저장소를 Import합니다.
3. 별도의 Build Command나 Framework Preset 설정 없이 **Deploy** 버튼을 누르면 10초 만에 전 세계에 무료 배포됩니다!
