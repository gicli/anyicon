AnyIcon Web 작동 원리 & 가이드

1. 왜 크롬은 못생긴 단축아이콘을 주나요?

Vercel 등으로 웹을 배포했을 때 크롬 브라우저는 웹사이트에 고해상도 Web App Manifest(192x192, 512x512)나 apple-touch-icon이 없으면, 도메인의 첫 알파벳 글자만 동그라미 안에 넣은 기본 단축아이콘이나 조악한 썸네일을 부여합니다.

2. AnyIcon Web은 어떻게 해결하나요?

모바일/태블릿: AnyIcon 런처 기술을 통해 사용자가 지정한 아이콘과 이름을 가진 맞춤형 PWA 런처를 생성합니다. 홈 화면에 추가하면 내 아이콘이 똭 박히고, 터치하면 즉시 원래 웹사이트로 이동합니다.
PC (Windows): 32x32, 48x48, 256x256 해상도가 담긴 진짜 Windows .ico 파일과 .url 바로가기 파일을 즉시 생성하여 바탕화면에 저장할 수 있습니다.
웹 개발자: Vercel 프로젝트에 그대로 넣을 수 있는 manifest 및 favicon 패키지(ZIP)를 제공해 근본적으로 해결합니다.

3. 기존 단축아이콘 드래그 앤 드롭 기능

바탕화면에 있는 기존 바로가기 파일(.url)을 드롭존에 끌어다 놓으면 웹사이트 주소와 이름을 자동으로 읽어오므로 번거롭게 URL을 복사하지 않아도 됩니다.
